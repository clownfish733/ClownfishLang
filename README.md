# Clownfish Lang

A fully custom Meta Programming Language written in rust. Implementing elements of imperative, functional and object oriented programming paradigms. 

---

## Features

- The most host language will have c style pointer access(potential even further insecurity) which will could be obfuscated in the higher level languages with rigorous testing of the lower level system which should be complete and semi-generatable by the compiler

- Compilers should be generated from the parsing of configuration files.

- Order 2 or greater compilers may use the custom configuration file formatting from the non-top-level language

- The host language should be extremely minimal yet complete (concurrency etc.)

- No Built in Garbage collector or reference counters although higher order languages could implement these

## Later-Features

- Conversion of other languages into specification in this language improving performance and allowing for unembedding and improved AI model training allowing for tokenisation of generic language

- Add syntax language and linting

- Formal mathematical style type systems (Sets or even category theory)
